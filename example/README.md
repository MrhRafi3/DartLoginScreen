# Rafi Login Template — Example Application

A demonstration application showcasing the `rafi_login_template` package in a realistic mobile application environment.

## Features Demonstrated

- **Direct Package Consumption**: Imports and embeds `RafiLoginScreen` as a full-screen mobile view.
- **Genuine Mobile Layout**: Demonstrates `SafeArea` handling, keyboard-adaptive scrolling, and reactive character animations.
- **Authentication Lifecycle**: Simulates asynchronous login requests with loading spinners, error messages, and success celebration animations.
- **Host Navigation**: Uses standard Flutter `Navigator` to transition to an authenticated dashboard upon successful login.

## Running the Example

From the root of this repository or the `example` directory, run:

```bash
cd example
flutter pub get
flutter run
```

### Running Tests

```bash
cd example
flutter test
```
